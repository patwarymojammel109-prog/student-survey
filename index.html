Firebase প্রজেক্ট সেটআপ (রিয়েল-টাইম ডাটাবেসের জন্য) Firebase Console-এ গিয়ে একটি জিমেইল অ্যাকাউন্ট দিয়ে লগইন করুন। Add project এ ক্লিক করে একটি প্রজেক্ট তৈরি করুন। প্রজেক্টের ড্যাশবোর্ডে গিয়ে Build > Realtime Database এ যান এবং Create Database নির্বাচন করুন। Database Rules অপশনে গিয়ে টেস্ট মোডে চালু করুন অথবা রুলস বদলে দিয়ে নিচে দেওয়া রুল বসান যাতে সবাই ডাটা দেখতে ও লিখতে পারে: JSON { "rules": { ".read": true, ".write": true } } প্রজেক্ট ড্যাশবোর্ড থেকে Project Settings (গিয়ার আইকন)-এ যান। Web App () আইকনে ক্লিক করে আপনার অ্যাপটি রেজিস্টার করুন। রেজিস্টার করার পর একটি firebaseConfig অবজেক্ট পাবেন। উক্ত কোডের const firebaseConfig = { ... }; অংশে আপনার অ্যাপের আসল Credentials বসিয়ে দিন। ২. GitHub Pages এ ফ্রীতে লাইভ করার উপায় GitHub-এ একটি বিনামূল্যে অ্যাকাউন্ট খুলুন। নতুন একটি Public repository তৈরি করুন (যেমন: child-survey). আপনার তৈরি করা ফাইলটির নাম নাম দিন index.html এবং রেপোজিটরিতে Upload files এর মাধ্যমে পুশ করুন। repository-এর Settings এ ক্লিক করুন। বাম পাশের মেনু থেকে Pages নির্বাচন করুন। Build and deployment সেকশনে Branch থেকে main বা master সিলেক্ট করে Save বাটনে প্রেস করুন। ২-৩ মিনিট পর আপনি একটি লাইভ URL পেয়ে যাবেন (যেমন: [https://yourusername.github.io/child-survey/](https://yourusername.github.io/child-survey/))।
